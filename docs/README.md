## Introduction

Echo is an assistive smart-glove system designed to translate Sign Language gestures into real-time speech and text. Communication between deaf or hard-of-hearing individuals and non-signers remains a significant challenge. Echo aims to bridge this gap through wearable technology integrating flex sensors, an ESP32 microcontroller, and machine learning models for accurate gesture interpretation.

## Hardware and Software Designs

- **Sensors & Processing:** Flex sensors mapped to finger bend angles, processed via ESP32.
- **Machine Learning & Gesture Recognition:** Classification models to identify static and dynamic signs.
- **Software Platforms:** Web and Mobile Application interfaces for audio playback and visualization.
